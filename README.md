# Titanic Survival Prediction

This is a beginner-friendly Machine Learning project that predicts whether a Titanic passenger survived or not.

## Project Goal

The goal of this project is to use passenger data such as age, gender, ticket class, fare, and family members to predict survival.

## Dataset

This project uses the Titanic dataset from Kaggle:

**Titanic - Machine Learning from Disaster**

Download `train.csv` from Kaggle and place it inside:
