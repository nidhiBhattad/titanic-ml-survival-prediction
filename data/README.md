# Titanic Survival Prediction

This is a beginner-friendly machine learning project that predicts whether a Titanic passenger survived or not.

## Project Overview

The project uses the Titanic dataset and applies data preprocessing, feature selection, model training, and model evaluation.

## Dataset

Dataset required:

data/train.csv

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression
- Decision Tree
- Random Forest

## Features Used

- Passenger Class
- Sex
- Age
- SibSp
- Parch
- Fare
- Embarked

## Models Used

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
